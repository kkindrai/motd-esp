# motd-esp
Simple spanish quote of the day.

## v1.0
Uses the https://www.positive-api.online/ API to pull quotes based on the day of the month. Will then generate a simple HTML document to host the page.

## v2.0
Uses a local .csv dataset that can be updated and filled with more quotes. Instructions to add more quotes below:
- To modify quotes, open /data/quotes-file-master.ods
 *  - Add/remove your quotes
 *  - SAVE AS `quotes-file.csv`.
 *      - Field Delimitter: `|`
 *      - "entrecomillar todas las celdas de texto" == TRUE
